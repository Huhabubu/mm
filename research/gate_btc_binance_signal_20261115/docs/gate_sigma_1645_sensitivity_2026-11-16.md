# Gate BTC/USDT 做市：90% 异常价差阈值敏感性实验

日期：2026-11-16。分支：`experiment/gate-btc-origin-90pct-20261116`。

## 研究目的

比较 **1.96σ（原 95% 正常带）** 和 **1.645σ（新增 90% 正常带）** 下 Binance 领动价差过滤能否稳定降低 Gate 永续合约 GLFT 的亏损，重点审计新增 `1.645σ < |G_t| ≤ 1.96σ` 区间的实际成交行为。

- `G_t=S_t^B-S_t^M-B_t`：当前 Binance 与 Gate 中间价之差减去过去 600 秒的时间加权平均价差。
- `σ_t`：同一 600 秒时间窗口的价差时间加权标准差，每 5 秒更新。
- 起跑基准价格只在 `|G_t|≤1σ_t` 时刷新，离开正常带即锁死；这是**两组共用**的起跑规则。
- 异常信号必须与 Binance 起跑后的价格变动同向，且其绝对变动超过 Gate；首次激活仍要求 Binance 自己的中间价在该时刻实际变动，处理同时间戳时采用保守规则。
- 报价模式、`β∈{0,.25,.5,.75,1}`、所有 GLFT 参数、Gate 合约数据、单笔名义约 80 USDT、库存 20 倍、风险厌恶 50 USDT⁻¹、20ms 单侧撤挂限制、2.5ms Binance 额外可见延迟、1ms 请求/确认延迟、官方 hftbacktest 2.4.4 保持不变。

**唯一的信号策略改变：** `abs(G_t)>1.96σ_t` 改为 `abs(G_t)>1.645σ_t`。`β=0` 基准应逐笔复现旧实验，用于跨实验一致性检查。

## 手续费口径

此前 1.96σ 实际 HBT 回测意外使用 Gate 公开合约 API 的 `maker_fee_rate=-0.0001`，属于返佣情景。用户明确要求正常扣费；这轮在 HBT 中**直接固定 Maker +0.0002（+0.02%，支付费用）**，Taker +0.0005（+0.05%），原 API 返回值单独保存。Post-Only / GTX 策略只能 Maker 成交。

同时报告：
1. **0 手续费的模拟净权益变化**：本轮 HBT 手续费后净权益 + HBT 实际已收手续费。
2. **Maker +0.02% 手续费后净收益**：本轮 HBT 直接记录的扣费后盯市权益变化。

原 1.96σ 比较组的对应结果从上次已完成的**相同模拟成交记录**重新计费：
- 原数据字段 `old_net`、`old_fee`，`old_fee<0`（原 Maker -0.01%）；
- `zero_fee = old_net + old_fee`；
- `maker_002_net = old_net + 3×old_fee`；
- `new_zero_fee = new_net + new_positive_fee`，`new_maker_002_net = new_net`。

每日报告是否改善及改善大小，不以 6 天累计盈利代替每日独立收益，并同时给出成交数、撤单量、信号激活数，辨别“少交易、少亏手续费”与“避开逆向选择”两种机制。

## 执行闸门

1. 复用原 6/6 完整日四流 Tardis QA，且 1.645σ 下边界单元测试通过。
2. 六个日期 `00:10–01:00 UTC` 50 分钟九模型工程验证通过后，运行 `00:10–24:00 UTC` 全日九模型（6×9=54）。
3. 抽查 `β=0` 的成交次数、零费净权益与 1.96σ 原实验严格一致；不一致则不报告跨阈值净收益比较。
4. 每日结果与全组 JSON/CSV 存档。六日已被研究过程反复使用，本次为**探索性敏感性分析**，不可作为未接触数据的样本外验证。

其他限制：暂未模拟资金费率、结束时主动平仓成本；Maker VIP0 费率场景应与实际账户历史等级区分；股票式 90%/95% 正态覆盖比例也不代表真实高频市场信号触发频率。
