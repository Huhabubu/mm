# 复现说明：依赖、命令、输入与验收

## 1. 复制原则

归档 `scripts/` 保留了 Gate 专属 Python 脚本的**原文件名及同级导入关系**，并原样附带这轮使用的公共 GLFT / 数据处理模块。原仓库的 `scripts/`、`docs/`、`reports/`、根目录 `.github/workflows/` 和 `progress.md` 全部保留，不因本次整理而变更。

本档案 `.github/workflows/` 是**历史工作流副本**，所在位置为 `research/gate_btc_binance_signal_20261115/.github/workflows/`，不在仓库根目录，因此**不会自动触发 GitHub Actions**。如果需要重新运行大数据回测，建议仍使用原来根目录的受维护工作流，或将归档视为固定快照另建独立实验分支。不要让归档副本与原工作流同时对同一结果目录写入。

## 2. 依赖

已审计的正式工作流使用 Python 3.11、`hftbacktest==2.4.4`、NumPy 和 Numba；安装命令在原工作流配置中为：

```bash
python -m pip install 'hftbacktest==2.4.4' numpy numba
```

有些下载和资料处理脚本还依赖 Python 标准库的 `urllib`、`gzip`、`csv`、`json` 等。运行期间需要能访问公开的历史 Tardis 下载地址与交易所合约元数据接口。**此归档没有重新锁定操作系统和所有转译依赖的精确版本，因此不保证脱离原工作流的本机运行百分之百字节级一致。**

## 3. 归档内的公共模块

为避免将原来 OKX/G0 研究代码改成另一个版本，以下文件都按原 Git 对象直接复制到归档 `scripts/`：

**这些模块在其他研究中的源文件保持原位，不允许仅因 Gate 归档而修改其计算含义、命名或导入路径。** 归档中每个复制件的内容对象 SHA 可以在 [文件清单.csv](文件清单.csv) 核对。

## 4. 用本归档的测试脚本做轻量核验

以下命令假设在仓库根目录执行，`ARCH` 指本归档位置。直接运行选定单元测试，不自动下载全日行情：

```bash
ARCH=research/gate_btc_binance_signal_20261115
PYTHONPATH="$ARCH/scripts" python "$ARCH/scripts/test_gate_origin_filter.py"
PYTHONPATH="$ARCH/scripts" python "$ARCH/scripts/test_gate_stage4_controls.py"
PYTHONPATH="$ARCH/scripts" python "$ARCH/scripts/test_gate_stage5a_pause.py"
PYTHONPATH="$ARCH/scripts" python "$ARCH/scripts/test_gate_stage5c_holdout.py"
```

Windows PowerShell 可以将 `PYTHONPATH` 设置为 `$env:PYTHONPATH="research/gate_btc_binance_signal_20261115/scripts"`，然后运行上述 Python 路径；文件夹相对路径要以当前仓库根目录为工作目录。测试的退出码为 0 才算通过，不要只看打印最后一行。

完整测试还应覆盖快照适配、同微秒事件顺序、HBT 原始成交精确重放、逐笔 Markout 价格年龄、收费符号和训练集参数冻结；相应原测试与工作流副本均已保留。

## 6. 非全量离线数据包

- `reports/` 包含 Git 已提交的汇总 JSON、CSV、图表、参数锁定以及报告，**不包含**全部 Tardis 原始 CSV.gz、全部 HBT `fills.npz`、`recorder.npz` 和逐笔 Markout `*_annotated.npz`。
- 原始成交、Recorder 和个别逐笔归因证据在 GitHub Actions 附件中；原工作流部分配置为保留 **90天**，到期可能无法再取得。
- 数据下载仍须检查历史合约规格、时钟和数据质量。复制现成 JSON 并不等于已经复现完整撮合。
- 手续费结论仍是 Maker +0.02% 的模拟场景，没有资金费率和期末主动平仓执行成本。任何研究复现不得把旧 Maker 返佣报告当作已盈利的结果。
