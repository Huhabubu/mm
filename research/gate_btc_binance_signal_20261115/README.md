## 为什么目录保留 scripts/、docs/、reports/

本档案按照原始仓库的相对目录复制：`scripts/` 放全部 Gate 专属 Python 代码、测试和依赖的公共模块；`docs/` 放全部原始研究方案和详尽报告；`reports/` 放冻结的数值结果、参数锁定记录以及图表；`.github/workflows/` 放自动运行配置的**仅供查阅的副本**。这种布局能维持 Python 的同目录导入，以及原始 Markdown 内 `../reports/` 等相对路径链接。

`.github/workflows/` 在本档案中嵌套于 `research/...`，**不会被 GitHub Actions 自动识别执行**；实际运行入口仍保留在仓库根目录原位置。全项目公共 `progress.md` 原样快照位于 `history/progress_full_snapshot.md`，其中含其他项目历史，本文请以本目录中文流程为阅读入口。

## 研究对象和固定口径

- 目标交易所：Gate 的 BTC_USDT USDT 永续合约；外部先导信号：Binance 的 BTCUSDT USDT 本位永续合约。
- GLFT（Guéant–Lehalle–Fernandez-Tapia）是基于库存风险与成交强度的做市报价模型；`hftbacktest==2.4.4` 是正式订单排队、撮合及延迟回放引擎，未自行替代。
- 主要开发历史日为 2026-06-01 至 2026-11-01 每月 1 日：每日前 10 分钟预热、其余 1430 分钟交易；2026-05-01 用于阶段④参数锁定，2026-04-01 用于阶段⑤事后历史稳健性检验。
- 主要正式信号：过去 600 秒的两所价差均值和标准差，每 5 秒更新；1σ 正常锚，1.645σ 激活门槛，必须满足 Binance 主动变价与方向优势；Binance 可见时间加 2.5ms 假设。
- 订单请求 / 回报模拟延迟各 1ms，同侧订单操作间隔至少 20ms；Maker（挂单）**收取 +0.02% 手续费**。每日收益指已扣 Maker 费的日末中间价盯市权益变动，暂未纳入资金费率和主动期末平仓成本。
- 已开发六日均在多轮研究中反复观察；4 月日早于后续模式训练选择日，属于历史稳健性检验；尚无严格时间向前的新样本外证据。
