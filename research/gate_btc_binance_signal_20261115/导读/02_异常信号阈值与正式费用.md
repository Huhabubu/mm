# 02｜Binance 主动变价、1.645σ 阈值与收费口径

## 研究问题

需要防止把 Gate 自己先动、两所共同上涨、或报价更新时间差造成的残差，误解为 Binance 独有的先导信息。

## 信号状态机（State Machine：有明确进入、维持和退出条件的规则）

令 `S_B` 为当时可见的 Binance 中间价、`S_G` 为当时可见的 Gate 中间价、`B` 为过去600秒按持续时间加权的正常跨所价差（均为 USDT/BTC）；`G=S_B-S_G-B` 为异常残差（USDT/BTC），`σ` 为相同窗口残差的标准差（USDT/BTC）。

1. `|G|≤1σ` 时更新两所起跑价；离开正常带时锁定起跑价。
2. `|G|>1.645σ`（原版门槛为 `1.96σ`）才进入候选。
3. Binance 起跑后的变动必须与残差同方向，并且绝对变动幅度大于 Gate。
4. 首次放行须由 Binance 中间价真实变化的事件触发；同时间戳来源不确定时保守剔除。
5. 有效信号退出后恢复原 GLFT 报价；持续期间可按照报价模式平移两侧或只移动风险侧。

具体实现与测试：`scripts/gate_origin_glft_strategy.py`、`scripts/test_gate_origin_filter.py`。

## 阈值对照怎么做

1. 在原九模型的信号与报价逻辑上只改变正常异常门槛：1.96σ → 1.645σ。
2. 原 GLFT β0 必须在新旧门槛回放中得到相同成交和权益，否则不能比较。
3. 两门槛均保留明确正手续费 Maker +0.02%，以各日净权益、成交量、撤单次数和相对差异为观察量；六个旧日期已经被探索，属于敏感性分析。

原始材料：`docs/gate_sigma_1645_sensitivity_2026-11-16.md`；脚本 `scripts/compare_gate_sigma_thresholds.py`；结果 `reports/gate_sigma_1645_vs_196/`。

## 手续费关键更正

最早 1.96σ 版本的 Maker −0.01% 意味着**每成交一次获得返佣**；后续改成 Maker **+0.02%（支付费用）**，所有策略在正式收费条件下绝对净收益为负。历史返佣文件原样保存供审计，绝不能作为当前论文的盈利证据。
