# 历史版本与费用口径：防止误用旧结论

此文件用于解释**保留但已被后续实验替代**的原始报告。归档不删除旧版本，因为需要记录研究如何发现和修正错误。

## 必须区分的三个阶段

1. **1.96σ 最初探索：Maker 返佣情景。** `reports/gate_origin_glft_full_day_aggregate/` 的最初六日九模型结果因从 Gate 公共 API 读取到 Maker `-0.0001`（相当于 −0.01%，每笔 Maker 成交得到返佣）而出现正值。该报告明确标记为历史含返佣情景，不能引用为普通正收费下的策略盈利。
2. **1.96σ 正手续费修正：Maker 收费 +0.02%。** `reports/gate_origin_glft_full_day_vip0_no_rebate/` 复用相同原始成交记录进行确定性收费重结算，正式净收益均为负。
3. **1.645σ 正手续费正式实验。** `docs/gate_sigma_1645_sensitivity_2026-11-16.md` 和 `reports/gate_sigma_1645_vs_196/` 记录门槛比较；阶段①—⑤以正式 Maker 正收费 +0.02% 的 HBT 回放与结果为主。

## 使用原则

- 所有讨论“策略盈利 / 扭亏 / 哪个模型更好”的主表，应首先呈现 **Maker+0.02% 收费后的净权益**。
- 对应零手续费的拆分仅可用于解释成交边际、库存价格损益或计算冻结路径的盈亏平衡手续费；不能作为真实收费策略的盈利 headline。
- 含费净权益尚未包括永续资金费率、账户实际 VIP 等级、期末主动清仓的价差与冲击、真实网络/采集时钟误差。
- 若未来使用真实账户费率，需锁定费率场景并重新检查其是否影响交易决策；不能混用不同手续费假设下的“六日最优”。
