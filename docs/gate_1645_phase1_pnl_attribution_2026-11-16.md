日期：2026-11-16；分支：`analysis/gate-1645-pnl-stage1-20261116`。基线为实验分支 `experiment/gate-btc-origin-90pct-20261116`，仅新增只读分析代码和合成单元测试。

## 样本和固定条件

2026年6–11月各1日 UTC 00:10–24:00，每日独立1430分钟，前10分钟预热。Gate BTC_USDT 永续，Binance BTCUSDT中间价，1.645σ双边β=1对原始 GLFT β=0。官方hftbacktest 2.4.4，Binance额外可见延迟2.5ms，订单请求和确认各1ms，Maker收费0.02%。原始官方HBT结果来自 [六日HBT #43786928308](https://github.com/Huhabubu/mm/actions/runs/43786928308)，每日期原生 `fills.npz` 与 `recorder.npz`。所有日期为已反复探索样本。

### 归因采样频率敏感性（关键限制）

如果改用每笔成交**之后第一条**100ms Recorder中间价作成交捕获，并把记录间价格变化归给区间起点持仓，两模型的日终收益保持完全一致，但六日日均分项变成：GLFT成交边际+7.513、库存−56.537；β1成交边际+4.268、库存−26.043。此口径下库存损益改善30.494 USDT/日，而上一口径为51.861。两种口径均数学闭合；这些归因数字受100ms采样时序影响，**不能据此量化逆向选择减少的因果份额**。需要更细粒度、与HBT成交时间统一的Gate行情来形成真正成交时刻的半价差与Markout。

## 阶段②和③输入完整性

| 数据对象 | 结论 |
|---|---|
| `fills.npz` | 6日×2策略成交齐全；含 `exchange_timestamp_ns`,`local_observed_ns`,`side`,`exec_price`,`exec_qty`，已与HBT笔数对齐 |
| `recorder.npz` | 6日×2策略齐全；有100ms `timestamp`,`price`,`position`,`balance`,`fee`，足够做阶段①、库存统计 |
| Gate原始逐事件行情 | 在原始HBT回放过程中存在，**未包括在最新结果归档**；100ms Recorder不足以精确计算成交后100/500ms/1s方向Markout、P10或尾均值，阶段②要重新下载/读取 Gate 行情并严格as-of对齐 |
| Binance信号完整有效区间 | 仅有策略定义及累计激活次数，**没有逐事件激活状态**；阶段③需按600秒时间加权基差/波动率、1σ锁定、1.645σ门槛、Binance先动/强弱和可见时戳重建信号；必要时只读官方HBT事件重放 |
| 挂撤单事件与ACK状态 | 结果归档无完整逐事件生命周期记录，不能把理论信号提前简单解释为已成功撤单 |
