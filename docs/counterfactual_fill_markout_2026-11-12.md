# 2026-11-12：OKX 基准独有成交、撤单确认与 100/500ms 逆向选择机制审计

**研究性质：已探索历史的机制检验。** 使用 Binance BTCUSDT / OKX BTC-USDT-SWAP（Tardis 原生行情），2026年6–11月每月1日、每天先10分钟GLFT校准、后50分钟交易；与既有正式结果使用同一份OKX融合行情、Binance外部可见事件时钟和官方 hftbacktest==2.4.4 订单模型（每侧20ms最小操作间隔、OKX请求/回报各1ms、固定Maker2bps/Taker5bps、原队列与库存参数）。真实实验的目标是检验减少的成交是否有更严重逆向选择。**未使用尚未探索的日期，不能推断为独立样本外结论。**

## 1. 成交对照定义与防止错误归因

在每个独立模拟策略的真实官方HBT成交中捕捉 **交易所成交时间戳、买/卖方向、订单实际挂单价格tick**，一笔一笔做三元组的**精确多重集合匹配**；同一个策略成交只能匹配一次，即使相同时间有多笔也不能重复借用。记录：
- 两策略同交易所时间、同侧、同价的共同成交。
- **仅纯GLFT有、β1在相同三元组上没有的基准独有成交**（候选“未重现”的订单）；不能自动叫成功撤单，因为β1的价格、库存、队列、订单有效期都可以不同。
- 仅β1发生的**新增报价成交**。这样净数量差=基准独有数−β1独有数，不能把净数量差当成撤单数。
- 附加HBT引擎确认CANCELED状态的订单记录（交易所确认时刻、方向、原订单挂价），仅在相同价和同侧、且确实早于基准成交的过去500ms之内，标成**成交价附近存在已生效撤单的关联代理**。该代理没有证明这个取消正是由Binance触发或此后没有重新挂回相同价，更不是充分的因果证明。
- 不使用Binance本地时钟对齐成交后markout：对所有HBT成交和OKX原生BBO统一采用**交易所时间戳**。计算成交前严格更早的OKX BBO中间价，未来100/500ms在目标时间之前最近一条BBO；参考价格必须在250ms新鲜度内，不符合者标为删失。成交方向调整：买为+1、卖为−1，价格变动除以成交前中间价×10,000，单位bps（基点）。负值表示对当前成交方向不利。另计算执行价格到未来中间价的净markout（减Maker2bps），区分净成交质量与中间价变化。
- 这里主要的成交前中间价到未来时刻变化**包含成交当刻附近的价格冲击**。下一步需要拆分第一个严格成交后BBO与后续走势，以识别更纯粹的成交后延续。

另外：
- β1**所有实际成交**：100ms有效1,184笔，不利比例**96.62%**，平均方向调整中间价变化**−0.896bps**；执行价到100ms未来中间价、扣Maker费后的平均净markout **−2.535bps**。
- β1的**1,016笔新增报价成交**：100ms有效1,008笔，不利比例**97.32%**，平均方向调整价格变化**−0.915bps**；这些是β1换到别处报价后产生的风险和手续费，不能只统计消失的β0成交。
- β1过滤版本：β0独有候选659笔，100ms有效651笔，不利比例**96.31%**，平均−0.999bps；保留同价同刻成交957笔有效、不利比例**97.28%**，平均−0.905bps。过滤版本按“不利比例”没有体现更精准的避险选择性。
- β=−1反向安慰剂：β0独有候选1367笔，100ms有效1355笔，不利比例**98.01%**；无方向P90扩价差对照：β0独有1627笔，100ms有效1601笔，不利比例**96.88%**。说明**即使不用正确的Binance方向，避免成交的集合通常也有非常高的不利比例**；不利比例高是基准成交的普遍特征，仍不足以证明正向Binance信号带来了有选择性的避险。

## 4. 先前净收益改善的会计分解

先前官方HBT六个50min：
- β0净权益合计 **−31.9731 USDT**，手续费22.3836 USDT。
- β1净权益合计 **−23.1210 USDT**，手续费16.6353 USDT。
- 净权益差**+8.8521 USDT**；其中手续费节省**5.7483 USDT**，其余加回手续费后的毛权益差**+3.1038 USDT**。手续费变化占观测净差约**64.9%**（仅会计恒等式、并不意味64.9%的因果作用已经被识别）。

在当前高频Maker手续费/成交后不利变动环境中，纯粹减少成交就很容易减轻负的净收益。先前无实时Binance方向的扩大价差对照，在六日期平均更少亏且成交量更低的事实，与此机制一致。

## 5. 可得结论与下一步

- **被β1改变掉的纯GLFT原报价成交，绝大多数伴随100ms/500ms不利中间价移动。这是回测数据支持的描述性事实。**
- **目前不充分支持“Binance准确识别并及时撤掉了这些危险单”这一强因果命题**：基准几乎所有成交都不利；反向安慰剂和无方向扩价差所排除的成交也高度不利；仅少量找到同价先前官方确认取消的代理，而且beta1还产生1016笔新的成交。
- β1净收益较好但仍然亏损，说明需要在**交易强度、报价存活时间、取消后是否重新挂回、成交质量与费用**之间细分作用来源，而不能继续只看收益和总撤单数。
- 建议下一项优先专注**真实撤单生效归因**：记录订单ID的提交→有效→取消请求→交换机确认→是否再次提交同价，以及在取消完成前发生的成交；再加入*完全无方向但订单活动强度可比*的对照，联合验证Binance究竟提升了选择性。此后跨未见日期/币种做独立验证。
- 本轮未改任何原GLFT持仓、报价参数、成交队列和费率。新增的订单机制记录是只读审计；六个日期β0和β1的**官方成交笔数、净权益与本轮以前的旧结果逐项完全相同**，没有审计侵入影响交易行为。
