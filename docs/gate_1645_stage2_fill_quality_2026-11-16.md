## 二、Markout 定义与统计口径

令 (t_i) 表示第 (i) 笔模拟成交**被策略本地观察到**的时刻，单位纳秒（比交易所内执行时刻晚 1ms）；(m_t) 表示 Gate Tardis 原生 quotes 已可见的最优买卖价中间价，单位 USDT/BTC；(p_i) 是成交价（USDT/BTC）；(d_i=+1) 为买入，(d_i=-1) 为卖出；(h) 为未来 100ms、500ms、1000ms 的观察期限：

[
M_{i,h}=10^4d_irac{m_{t_i+h}-m_{t_i}}{m_{t_i}}quad(mathrm{bps}),qquad
C_i=10^4d_irac{m_{t_i}-p_i}{m_{t_i}}quad(mathrm{bps}).
]

- (M_{i,h}<0)：买后下跌或卖后上涨，即负方向 Markout；(C_i) 是以本地观察中间价计算的捕获半价差。
- 入场中间价采用**严格早于**本地成交观察时刻的最后一条 Gate quotes，排除同一微秒无法判断的事件顺序；未来中间价仅使用 `local_timestamp ≤ t_i+h` 的最后已到达报价。以未来数据计算结果标签，不将其输入策略。
- 主口径要求两个端点所用报价的年龄均不超过 **500ms**，且未来端点不越过该 UTC 日。捕获半价差与 Markout 在同一批有效成交上比较。缺失不填零，报告覆盖率。
- 名义额权重：(w_i=p_iq_iv)（USDT），其中 (q_i) 是 Gate 合约张数，(v) 是 BTC/张的合约乘数。分别计算逐笔算术均值与成交名义额加权均值、负比例、P10（第10百分位）、尾部最差10%平均值。名义额加权尾部按最差10%**名义额**取平均，边界权重可部分纳入。主结果先按日统计，再对六日等权；不是将六天的每笔成交汇总作权重。

## 四、研究判断与阶段③前置

1. **已证实的描述性事实**：β1减少约35.3%官方成交笔数；成交后100ms平均负向Markout绝对幅度由1.199缩至1.081bps；成交捕获半价差也从0.830缩至0.783bps；尾部损失平均值有所缓解。
2. **尚待识别的机制**：这可以来自减少成交暴露，也可能来自信号筛选、不同库存路径和不同价格下的队列。已成交样本的Markout改善不能推算为全部未成交/被取消订单的潜在逆向选择，更不能把100ms/500ms Markout加到阶段①真实库存盈亏里。
3. **下一阶段限定**：只重建 600s 时间加权价差基准与标准差、每5s更新、1σ价格锁定、1.645σ信号阈值、Binance主动变价激活条件、2.5ms模拟可见时间及HBT订单时间线；再对原GLFT的成交做受威胁侧/另一侧/未激活三组比较，并核对理论可反应与已确认撤单。单纯 `abs(G)>1.645σ` 分类会错误纳入尚未放行的信号。
4. 继续保持既定Maker费率、原始GLFT与β1、报价/撤单节流及延迟不变；六日期有前视研发选择风险，还未覆盖资金费率及真实期末平仓成本。
