# G0 队列一致成交强度估计：事前协议（2026-11-10）

本实验只验证成交到达模型：使用官方 hftbacktest 2.4.4 的队列、撮合、延迟和 GT​X(post-only) 限价单，对 OKX BTC-USDT-SWAP 的 Tardis 行情做训练/留出期分离。**原始 G0 报价代码不变，既有 174 档半价差及两笔成交收益仍保留为待修诊断。**

## 参数与单位

训练 UTC 2026-11-01 00:00–00:10（6000×100ms），留出 UTC 00:10–00:20（实际可能早于末尾少量间隔结束）。BTC-USDT-SWAP：tick=0.1 USDT/BTC，lot=0.01 张，ctVal=0.01 BTC/张，maker 单 0.1 张。固定 1ms 进单与 1ms 回应，power_prob_queue_model(2.0)、no_partial_fill_exchange。九个目标距离 0.5/1/2/5/10/20/35/50/100 个真实 tick，每个距离和时间窗口独立重放，订单每 100ms 重新检查目标档位，持仓限额 ±2 张。

## 活跃挂单曝光时间（exposure）

官方库订单 `status=NEW/PARTIALLY_FILLED` 时视为已经接受、当前存续的挂单；`NONE` 为在途提交请求，不能计入曝光。每 100ms 区间开始，读取 hftbacktest 订单状态、订单实际价格和当时可见中间价。有效订单按真实半档距离分组，对后续完整成功重放的 100ms 计 0.1 个订单秒（两侧订单分别累计）。区间内是否取消由官方撮合和订单延迟模拟，**存续时间按区间起点离散估计**，每次状态切换存在不超过一个采样间隔的计时误差，尚需 finer-step 试验。

区间末尾从 `FILLED` 状态读取官方模拟成交，按区间开头同一订单的真实价格档位归集。区间开头尚未收到接受回应但区间中途成交的记录（no observed exposure）单独列为 unmatched，不强行分配曝光时间或拟合强度。提交、撤单、库存和已接受曝光分别计数并进行核对；不会用仅按历史成交价格穿价的代理替代官方实际成交。

## 估计与验证

对于每个有效距离分组 d（实际半档距中间价，单位 tick），令 E(d) 为该距离两侧有效挂单累计秒数，N(d) 为同组官方回测模拟 maker 成交笔数。采用泊松强度模型（Poisson intensity model）：N(d) ~ Poisson(E(d)*A*exp(-k*d))。A 是每个有效 maker 订单每秒的理论成交强度尺度，k 是单位 tick 的距离衰减系数。通过对数链接和 offset log E(d) 的二参数最大似然估计（MLE）同时使用正成交和零成交但有曝光的分组；若 k<=0、事件/曝光不足或求解失败，输出无法通过验证而不是强行给 GLFT 报价。

仅使用训练窗口拟合 A、k，并原样在独立留出期按真实观察到的曝光时间预测成交数；比较样本外泊松偏差（deviance）和训练期常数强度模型的相同指标。九个距离重复播放**同一历史行情**，各距离及买卖侧的成交相关，模型拟合仅为诊断点估计，不适合把它们当作独立数据计算 p 值或标准误差。

## 不能直接作为最终 G0

活跃时间按 100ms 间隔近似、订单状态只在本地回应后可见，订单生效与响应之间有时差；若出现未配对成交必须检查其量级。还要验证实际报价距离是否因市场变动成为 stale order，检查不同队列/延迟模型、未来日期的预测能力，才能用于正式策略。gamma=0.05 仍是原始情景风险参数，本轮不动，只有估计可信后才考虑应用 GLFT 报价。

## 2026-11-10 10ms 曝光计量精度补充协议

保持报价决策的 100ms 时钟，诊断程序增加对已接受订单的 10ms 状态采样；同时在同一次 GitHub Actions 中用完全相同的 20min Tardis 数据与 hftbacktest 配置独立重放原 100ms 计量版本。两组都使用相同的 9 个目标距离、订单规模和库存上限，不调整模拟撮合规则、Gamma、手续费或真实历史数据。

每 10ms 只执行引擎时间推进、读取有效订单状态并记录时间归属，报价与撤单决策仅每第 10 个采样间隔执行一次。分别按相同训练窗口拟合 A、k，并用同一留出期的匹配成交数/曝光时间计算泊松偏差。比较成交和未匹配比例时必须报告绝对计数及分母，并逐一对账各距离的策略下单、撤单、真实引擎成交、100ms 决策次数。若采样精度改变了真实撮合成交或报价决策，先核查驱动与事件时序，不将参数差异直接解释成采样误差。

10ms 仍然是离散曝光近似，订单实际在一个区间内生效或成交时的存续时间未知；未匹配成交需要保留，不准强行归入某个距离。公开结果只存聚合 JSON，原始 Tardis 数据不上传。此测试只诊断估计精度，不将新 A、k 或模拟收益直接写入正式 G0。
