# Gate SOL / DOGE × Binance：跨币种 GLFT 完整日实验（2026-11-17）

> 来源：GitHub Actions [六日期 SOL/DOGE 四模型实测 #44105647670](https://github.com/Huhabubu/mm/actions/runs/44105647670) 以及 [SOL 10月尾部验证 #44107555048](https://github.com/Huhabubu/mm/actions/runs/44107555048)。本报告只汇总实际完成的官方 hftbacktest 2.4.4 历史回放，未完成日期不能填零。

## 1. 实验规则与跨币种适配

- 目标市场：Gate `SOL_USDT`、`DOGE_USDT` 的 USDT 永续合约；信号分别为 Binance `SOLUSDT` 和 `DOGEUSDT` 原生最优买卖价。每天 UTC 00:00—00:10 预热，00:10—24:00 连续 HBT 回放（1,430分钟）。
- 日期：2026-06、07、08、09、10、11月每月1日，各币种六个候选日；全部使用 Tardis 免费历史行情。保留前10分钟最初 GLFT 的 A/k 识别保护。
- 交易执行：Binance 的 Tardis local_timestamp **额外**2.5ms信号可见延迟，订单请求和回报分别1ms，同侧最小下单/撤单间隔20ms。官方 HBT 的 `power_prob_queue_model(2.0)` 和 `no_partial_fill_exchange()`，GTX/Post-Only单。
- 收益：每个独立日原生 HBT 以 Gate 中间价盯市的 **Maker +0.02%（2bps）手续费后净权益**，未经资金费率或期末主动平仓成本调整。4个模型：原始 GLFT（β=0）、双边平移 β=1、单侧外移 β=1、单侧暂停 β=1。跨所信号保持原600s常态基差、5s重估、1σ锚、1.645σ激活门槛与 Binance主动变价来源条件。
- 合约：当前 Gate API 明确按 `X-Gate-Size-Decimal: 1` 读取小数张下单规格；数量单位保持 Gate“合约张数”。SOL 实测 `ctval=1 SOL/张`、`tick=0.01 USDT/SOL`、`lot=0.1张`；DOGE `ctval=10 DOGE/张`、`tick=0.00001 USDT/DOGE`、`lot=1张`。价格 `Mid_Binance-Mid_Gate` 直接以 USDT/币相减，不乘 `ctval`。当前 API 的实际返佣字段不用于替换旧BTC统一的 +0.02% Maker **实验费率**；历史费率与合约规格仍须另行核验。
- 单笔名义目标80 USDT，按预热中间价和合约最小下单张数取整，库存绝对上限20倍该笔数量。经济财富风险厌恶系数固定 `Γ_USDT=50 USDT^-1`；代码参数 `γ_code=Γ_USDT·ctval·tick`。
- 原先 BTC 完整日数据和策略定义均保持冻结；SOL、DOGE 使用相同 GLFT 参数估计与报价/成交引擎。原始历史全日 CSV 使用60min分段转换为HBT NPZ，单个HBT引擎贯通全部分段，库存、订单队列与滚动估计状态不重置。
- Markout：成交回报在本地可见后，对齐 Gate 原生 quotes 的100/500/1000ms方向化中间价变化；主口径起点与终点各自报价年龄≤500ms。新鲜度阈值只用于成交质量统计，不改变挂单行为。

## 3. 质量闸门、失败机制与样本局限

1. **小数张 API 读取：** Gate SOL 的旧默认 API 整数输出把实际 `order_size_min=0.1` 截断为0；改用 `X-Gate-Size-Decimal: 1` 后，SOL 最小张数0.1、DOGE最小张数1正确识别。已加入合约值、数量网格和标的匹配的聚焦单元测试。
2. **前10min GLFT 识别：** SOL 8、9、11月与 DOGE 11月不能通过既定严格初始A/k拟合门槛；即使随后可以观测更多交易，本轮仍保持10min与BTC一致，拒绝将缺失记为零，也未临时改变70个距离阈值或拟合要求。
3. **SOL 10月当日尾部：** 初次完整日回放达到863993个100ms采样点，距离约864000的整日目标少7个采样点（约0.7秒），旧通用汇总允许误差5个采样点；既有 UTC 日终检查允许≤1秒。独立[复跑 #44107555048](https://github.com/Huhabubu/mm/actions/runs/44107555048)将**仅新增跨币种场景**容差上限调整为10个100ms采样点，保留原 BTC 默认5个采样点、实际末端≤1秒检查与成交/数据QA，其余四模型全部完成；实际四模型均缺7个点。
4. **价格离散性：** SOL 有效日相对价格档为0.848—1.358 bps；DOGE为0.994—1.436 bps，远高于此前BTC细Tick，可能使小幅跨所信号取整后不能改变真实报单档位。仍需单独审计“信号激活→理论偏移→实际报价档位改变”分解。
5. **数据与费用：** 仿真采用2026-11当前 Gate 合约规格，通过历史价格/成交网格QA；尚未核实全部历史合约元数据是否变化。Maker统一设定为+0.02%收费，不等于当前 Gate API 上显示的账号/档位返佣。Tardis Gate L2 部分来源为周期性快照转换出的增量，与真实交易队列位置存在不可消除的估计差异。
6. **局限：** 各币种有效日期不同、样本历史已探索，不能把本次结果宣称严格样本外；样本数3与5较少，不能推断稳定统计显著性。真实跨所路由延迟、资金费、期末主动平仓、撤单逐笔生效审计仍需后续检验。SOL 100ms报价有效覆盖率约94%，DOGE仅约84%，两者Markout基于按自身样本筛选后的成交。
