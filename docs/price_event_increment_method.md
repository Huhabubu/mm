# 价格事件条件下的 Binance 增量预测检验（预设方法）

研究对象：OKX BTC-USDT-SWAP 的原生 BBO（Best Bid and Offer，最优买卖报价）未来中间价收益。所用报价来自 Tardis `book_ticker`，Binance 为 `BTCUSDT`，OKX 为 `BTC-USDT-SWAP`。

## 问题与可比较设计

**在 Binance 本身出现中间价变化的同一批决策时点，额外观察 Binance 的方向和变动幅度，能否降低 OKX 未来收益的样本外预测误差？**

- 事件定义：遍历 Binance 原生 BBO 文件，发现中间价相较上一条有变化后，每个 20ms 时间桶只选第一条价格事件。顺序采用文件原始记录顺序，同微秒多个事件不读取后续行。
- 决策时间：Binance 事件的 Tardis 采集时间加假设额外等待 0/25/50/100ms。
- P1 特征：OKX 当前前的 100ms/500ms 中间价收益、OKX 最优档挂单量不平衡、价差、OKX 最近报价年龄。
- P2 特征：P1 五项 + Binance 当前价格变化方向（±1）、相对于上一条 Binance BBO 的有符号中间价变动幅度（bps），**总共七项**。
- 目标：决策时间到未来 20/50/100/200/500/1000ms 的 OKX 原生中间价收益，单位 bps。两模型**使用同一时点、同一 OKX 标签**。
- 时间可用性：所有 OKX 自变量采用严格早于决策时刻的最新 BBO 记录；若该微秒恰有 OKX 新报价，丢弃该事件以回避两所采集器不能确定同微秒内部先后顺序的问题；目标使用不晚于未来终点的最新 OKX BBO。
- 方法：固定正则化强度为 0.01 的岭回归，训练日期内估计特征均值/标准差及回归参数。无超参数搜索。
- 划分：2026 年 6—8 月每月 1 日训练；9 月 1 日诊断；10—11 月 1 日探索性测试。历史测试日已被研究人员多次查看，**本轮结果不得作为全新盲测显著性证据**。
- 指标：测试日逐日 P1/P2 均方误差（MSE，平方 bps）、相对改善百分比、零预测误差、非微小价格变动比例、条件方向正确率；两个探索测试日每日等权。暂不做逐事件伪独立显著性检验。
- 预期决策：在多个日期/延迟下 P2 相对 P1 是否可复现优势；如果增量不稳定，暂不进入 GLFT 的参考价平移 A 回测。

## 识别边界

- P1 和 P2 的评价样本都以 Binance 价格变化事件为触发条件。P1 **没有收到 Binance 的价格变化方向/幅度**，但其决策时刻的选择依赖 Binance 事件。此设计是给定事件出现后的**特征增量检验**；它不等于一个完全只用 OKX 自己信息触发、可独立运行的 P1 做市策略。
- Tardis 两所采集器位于同一东京区域，仍不能无偏确定同一策略主机可见的跨所事件顺序。延迟模拟是敏感性测试。
- 6—8 月与 9—11 月跨越 OKX 交易所服务器迁移，不同数据时期的预测回归关系可能出现结构变化。
- 预测性能和交易利润是不同目标；即便 P2 有正向增量，仍需后续加入合理的订单撤销/下单延迟、手续费和成交队列模型。
- 本轮保留已有实验、不引入 OFI、不改变 GLFT 设定，仅实现与检验同事件的 P1 对 P2。
