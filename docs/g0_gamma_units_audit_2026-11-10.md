# G0 GLFT 风险厌恶系数 γ 单位审计（2026-11-10）

## 审计范围、结果

依据仓库现行主分支 `scripts/g0_glft_baseline.py` 与 `scripts/g0_glft_rolling.py`，使用 `GAMMA=0.05`、每单 `ORDER_QTY=0.1` 张、`CTVAL=0.01` BTC/张、`TICK=0.1` USDT/BTC/档、库存绝对上限 `POSITION_CAP=2` 张。`GAMMA` 是固定**情景数值**，未用行情/效用估计，既不会在每 5 秒更新，也没有与合约面值联动。滚动更新的只有成交强度 (A,k) 和价格波动率 σ。

### 1. 原公式与当前实际实现

当前 GLFT 近似采用 ξ=γ，报价相对于中间价的 `half=c1+Δ*c2*σ/2`，库存斜率 `skew=c2*σ`，实际 `reservation = mid − skew*position`。这里 `mid`、half、sigma 按**真实价格档**，`position`、Δ 按**合约张数**，指数到达模型的 k 按**每真实档的倒数**。因此代码中 γ 必须以 `1/(张*档)` 的等价规模理解，不能无条件解释为 `1/USDT`。

公式：`c1 = log(1+γΔ/k)/(γΔ)`，`c2 = sqrt(γ/(2AΔk) * exp((k/(γΔ)+1)*log(1+γΔ/k)))`，`half = c1 + Δ*c2*σ/2`，`skew=c2*σ`。`A` 单位 1/sec，`k` 单位 1/档，`σ` 单位 档/√sec，`Δ` 单位 张。

### 2. USDT 财富单位的映射

若使用常绝对风险厌恶指数效用（CARA）`U(W)=-exp(-Gamma_USDT*W)`，其中终端净财富 `W` 用 USDT 表示、`Gamma_USDT` 的单位为 1/USDT。设 `B = CTVAL*TICK`（每张每个价格档的 USDT 盈亏敏感度），本合约 `B=0.01 BTC/张*0.1 USDT/BTC/档 = 0.001 USDT/(张*档)`。写成 `W/B` 的合约张数×价格档尺度，**应有** `gamma_code=Gamma_USDT*B`。现行 `gamma_code=0.05`，则对应 `Gamma_USDT=0.05/0.001=50 1/USDT`，指数效用绝对风险容忍度 `1/Gamma_USDT=0.02 USDT`。这仅为理论等价映射，无法从仓库确认作者当时真正采用了这样的 USDT 风险偏好。

**这不是建议直接将 0.05 改成某个数**：如果设定 `Gamma_USDT=0.05 1/USDT`，等价的代码值是 `gamma_code=0.00005 1/(张*档)`；这表示全新风险偏好，必须通过事前风险预算、真实订单名义金额与风险库存分析决定，再进行敏感性比较。

### 4. 单位不变性与手续费边界

将风险厌恶转回 `Gamma_USDT=50 /USDT`、订单量转为 `0.001 BTC`、k 转为 `(USD/BTC)^-1 = k_tick/0.1`、波动率转为 `sigma_tick*0.1 USDT/BTC/√sec`，同一公式计算的**价格单位半价差**应等于原 `half_ticks*0.1 USDT/BTC`，库存斜率也必须可精确换算；回归测试检验该不变性。

以**示意价格** BTC=77,500 USDT、maker 费率=2bps=0.0002：单次挂单 0.1 张=0.001BTC 名义额 77.5USDT，单次 maker 手续费 0.0155USDT，相当于每 BTC 15.50USDT、**155 个真实价格档的单侧收益**。现有 G0 计算的半价差 36–122 档均低于**仅靠该半价差支付单侧 maker 费用**所需的 155 档；这是静态零漂移、成交价格相对中间价的费用比较，未涵盖后续 mid 变化、库存调整和动态策略收益，不能当作严密盈利不可能定理。

## 5. 审计结论与处理顺序

1. 已确认：`γ=0.05` 来自手动情景值；代码中它作用于 `γ * Δ`，不随 5 秒滚动窗口更新、未映射 USDT 真实风险容忍度。官方教程本身也说明 `gamma=0.05` 属人为选择，且使用 `delta=1`。
2. 已确认：代码**没有在计算报价时乘上合约面值/价格档的换算因子**，因此若目标是将 γ 定义为以 USDT 计价的 CARA 风险厌恶系数，需要显式转换，不能以固定的 0.05 跨币种直接使用。
3. 待决策：应事前定义合理的 USDT 资金风险容忍度或最大允许库存风险（与真实做市账户预算、头寸杠杆匹配），再将其映射为每个合约的 gamma_code，并对不同风险偏好进行保持其他条件不变的消融对照；**审计阶段不修改 G0 交易 gamma**。
4. 即使把 gamma 改成较小数值，初次 (1/k ≈ 95.55) 档仍在 35 档拟合深度之外，说明**风险单位修复无法单独解决成交强度外推问题**。需独立检查 k 的估计区间、价格事件过度跳动与 maker fee 经济约束。
