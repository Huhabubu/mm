## 核心发现

**四市场毛亏损的直接会计来源，是成交时虽然取得正的相对中间价优势，但持仓期间中间价朝不利方向变化，损失超过了该成交优势。** 即使Maker费率设为零，这段历史下绝大部分模型的毛收益仍为负。

**Binance信号当前主要减少持仓价格损失与手续费，其每笔成交的平均后续价格不利程度改善有限。** 这支持“成交变少、暴露变小”的解释；尚未证明“更精准地筛掉特别有毒的成交”。

### 数学定义

`ε_i` = 第i笔成交方向（买+1、卖−1，无量纲）；`q_i` = 成交数量（该所原生合同/基础币数量单位）；`v` = 每单位下单数量对应的基础币数量（币/张或币/单位）；`p_i` = 官方HBT成交价格（USDT/币）；`m_{τ_i}` = 成交在策略本地被观察到时，目标所Tardis原生BBO中间价（USDT/币）；`Q_{j-}` = 第j次BBO报价更新之前按HBT成交记录可见的库存（下单数量单位）；`m_j` = 第j次BBO新中间价；`Q_T` = 策略末库存；`F` = HBT实际累积手续费（USDT）。

\[
 E=\sum_i \varepsilon_i q_i v(m_{\tau_i}-p_i),\quad
 H=\sum_j Q_{j-}v(m_j-m_{j-1}),\quad
 C=Q_Tv(m_T^{\mathrm{HBT}}-m_T^{\mathrm{BBO}})
\]

\[
 \Pi_{\mathrm{gross}}=E+H+C,\qquad
 \Pi_{\mathrm{net}}=\Pi_{\mathrm{gross}}-F.
\]

以上等式由实际HBT成交现金流重建并严格对账，20个有效市场×日期案例的四个模型全部通过。成交价相对BBO的即时边际`E`为正不意味着每一笔成交都盈利，因为持仓造成的`H`为负。

## 3. 100ms和500ms成交后逆向选择（markout）

`markout` = 成交后一定时间市场价格朝**成交持仓方向**的变化。买单在成交后跌价、卖单在成交后涨价，按此定义为**负向**。这里使用成交在本地观察到的时刻作为零点，100ms、500ms分别衡量之后的报价中间价方向变化，均从目标交易所Tardis原生book_ticker按**当时已采集可见信息**读取，禁止前视。

| 目标市场 | 成交总数 GLFT→β1 | 100ms不利成交比例 GLFT→β1 | 100ms平均方向变化(bps) GLFT→β1 | 500ms平均方向变化(bps) GLFT→β1 | 100ms有效覆盖 GLFT→β1 |
|---|---:|---:|---:|---:|---:|
| OKX BTC | 1590 → 896 | 96.587% → 96.745% | -1.058 → -1.016 | -1.200 → -1.162 | 1582/1590 → 891/896 |
| OKX SOL | 314 → 276 | 89.389% → 88.192% | -1.691 → -1.463 | -1.915 → -1.627 | 311/314 → 271/276 |
| BITGET BTC | 788 → 598 | 96.498% → 96.194% | -1.142 → -1.142 | -1.320 → -1.317 | 771/788 → 578/598 |
| BITGET SOL | 1913 → 1873 | 98.098% → 97.248% | -1.211 → -1.187 | -1.336 → -1.311 | 1788/1913 → 1744/1873 |

在本模拟交易中，除OKX SOL只有两日且有效成交更少外，其余市场约96%—98%的合格成交，在成交后100ms显示负向价格变动；**无论β=0还是β=1，负向成交比例都很高**。例如 OKX BTC：GLFT 100ms负向成交比例约96.59%，Binance版约96.75%；平均100ms markout从−1.058bps略改善到−1.016bps，但**没有显著改变负向成交比例**。Bitget BTC平均100ms markout两者几乎一样（−1.142bps）。

这些结果说明：
- Binance版总体**成交次数和持仓暴露**减少，并降低手续费和库存亏损；并不能据此说每次被过滤掉的成交“主要是有毒成交”。要判断信号能否真正筛选逆向选择，下一步必须构造**β0独有成交与共同成交的同市场、同事件时间配对**，比较对手模型是否原本会成交，以及给定仓位/交易频率下的净效益。
- 100/500ms markout是附加诊断，**不能再加到持仓损益中**；持仓损益已计入持有期间全部中间价变动。
- 局部峰后处理虽然在当前样本减少总体净亏损，很多市场每笔成交的100ms markout反而更负，提示“少成交≈少损失”与“成交质量提高”必须区分。

## 4. 数据质量、可重复性和限制

- 80个有效模型回放均根据官方HBT独立生成的真实模拟成交数量、成交价和方向、余额、持仓、费用、期末市场中间价严格重建损益。对账容忍绝对误差0.00015USDT；实际通过。
- 100/500ms的报价取成交观察时钟下的原生BBO，出于鲁棒性仅使用BBO采集年龄≤500ms的记录；输出逐笔带成交交易所时间、策略观察时间、成交方向、成交价量、当时与未来BBO、报价年龄、两档markout、有效性标识的派生NPZ，便于后续复核与审计。
- HBT设置的回报延迟为1ms，审计日志核对的`本地观察时刻−交易所成交时间`中位数为1ms；目前后续100/500ms窗口以**收到成交回报**起算，而非在真实交易所执行那一纳秒起算。此前1ms变化未被视为零，且跨所Tardis采集时钟、实盘网络路径仍存在校验需求。
- OKX SOL四个历史日期的10分钟校准中有效距离档不足（小于5档）而无法估计，未将无效日收益伪装成0，导致只有2天可供定量比较；四市场的共同可估计日期也只有这2日。
- 研究仍然基于既有6个月首日的**前50分钟**，不是6个完整自然日，也没有新样本外检验。资金费率、期末实际平仓冲击、真实交易限频、撤单确认与历史手续费等级未全部验证。
- **论文解释应限定为描述性交易质量和严格会计归因**：负向成交后markout说明样本里所成交订单普遍承受不利价格变化，但不能推导“所有未成交/撤单都是逆向选择”或“Binance信号已被证明具有独立预测优势”。
