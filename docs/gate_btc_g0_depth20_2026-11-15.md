# Gate BTC 20档 GLFT 首次真实回测（2026-11-15）

## 实验边界
- 分支：`experiment/gate-btc-glft-depth20`；保留主线其他市场 G0/G2 代码默认行为。
- Tardis：`gate-io-futures/BTC_USDT`，2026-11-01 UTC，00:00–00:10 仅校准，00:10–01:00 交易。
- 官方 hftbacktest==2.4.4，输入 `incremental_book_L2`（初始快照及后续盘口变化）+ `trades`，`tardis.convert(...,snapshot_mode="process")`，无 Gate 原生 BBO、无 Binance 外部信号。
- 保留当前 G0-R 的过去 600秒/100ms 样本窗口、每5秒重估 GLFT A/k/波动率、原0.5–35真实tick成交强度估计区间和事件驱动报价。每侧订单操作最短间隔20ms；官方引擎固定请求/回报延迟各1ms、power_prob(2)队列和无部分成交模型。
- Gate BTC 公开合约单位：tick=0.1 USDT/BTC、每张合约=0.0001 BTC、订单精度1张，沿用前期跨市场实验的约80 USDT每单、50/USDT的财富绝对风险厌恶、20×订单规模库存上限。
- 为与旧 G0 对照保持一致，费用是假设 maker=2bps/taker=5bps；Gate 当前公开接口返回的 maker=-1bps（返佣）、taker=7.5bps，与假设不同，**此结果不能被称为 Gate 账户真实费率表现**。历史账户费率尚未确认。
- 试验两策略：`raw_glft` 原始 GLFT 报价；`depth20_glft` 仅在原始报价越过目标侧第20个可见、数量>0的价格层级时强制移到第20档，不使用20个tick代替20个非空价格档。若不足20个价格档，暂停该侧新增报价。GLFT拟合保持原样。

## 参数拟合
- 两策略完全相同：初次10min校准成功，之后每5秒更新；601次尝试、601次成功、0次拒绝。
- 初次拟合 A=0.07544698每秒、k=0.00959471/真实tick，波动率=17.8812tick/sqrt(s)，半价差114.53tick。

## 不能越界解释的地方
1. 数据仅1天内前50分钟交易，不能代表全天或独立统计样本。当前未加入 Binance 信号，因此结果只检验 Gate G0 与截断规则。
2. Gate 旧版20档历史盘口无法持续观察远档的真实队列；**原始 GLFT 越过20档后的36笔模拟成交属于低可信度执行结果**，不应直接视为可信的原始 GLFT 盈亏基准。
3. 截断到第20档后，成交增加同时导致撤单请求约9倍；交易所真实 API 限频、请求拒绝、订单到达/撤单生效延迟尚未回放。离散盘口快照更新也可能扭曲队列位置。
4. 本次20档阈值是每侧第20个**非空价格层级**，不等于0.1USDT×20；截断频率不能从GLFT半价差的tick值简单计算。
5. 本分支是独立技术探索，不把新增收益/亏损解释为跨交易所价格信号的效果。
