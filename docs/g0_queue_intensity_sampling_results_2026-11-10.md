必须保留的计量误差：10ms 时间仍按区间起始订单状态计为完整 10ms 曝光，订单实际接受、取消或成交可能发生在区间中途；尚未得到连续精确的交易所生效时间。原 100ms 在途成交遗漏已从训练 16 降为 3、留出 18 降为 5，不能称为完全消除。

## 2. 强度拟合与样本外对照

用训练窗口中按**实际半档距离**分组的已接受订单秒 E(d) 与可归属模拟成交 N(d)，做泊松最大似然估计（Poisson MLE）。模型约束 E[N(d)] = E(d) × A × exp(-k d)，d 单位为实际 tick。训练及留出结果如下：

| 项目 | 100ms | 10ms |
|---|---:|---:|
| A（每活跃订单秒） | 0.029325379 | **0.031200397** |
| k（每实际档倒数） | 0.026254707 | **0.025388125** |
| 训练纳入拟合的成交（0.5—100 档） | 198 | **213** |
| 训练纳入拟合的曝光秒 | 9914.20 | **9928.79** |
| 留出拟合范围内可归属成交 | 156 | **170** |
| 留出预测成交 | 204.852 | **220.217** |
| 相对实际留出成交的数量高估 | 31.32% | **29.54%** |
| 留出常数强度模型预测成交 | 202.761 | 218.067 |
| 留出指数模型泊松偏差 | 44.329 | 79.616 |
| 留出常数强度泊松偏差 | 86.332 | 132.396 |
| 沿用旧 sigma、gamma 的 GLFT 计算半价差 | 55.20 档 | **56.03 档** |

**解释限制：** 10ms 多捕获了此前未配对的成交，也增加了可观察的实际距离分组（训练有效分箱 86→101）。两种观察频率的泊松偏差直接比较数值大小会混淆评价对象变化，因此仅在各自观测口径内比较指数模型与常数基准。两种口径下指数模型均优于常数基准的分组预测，但对总成交数都高估约三成；不能说 10ms 已经证明交易模型可靠。不同目标距离重复使用同一历史市场路径，彼此相关，不能据此得到独立的显著性检验。

GLFT 半价差只是把各自 A/k、旧训练波动率 sigma≈13.088815 tick/√秒、研究预设 gamma=0.05、订单规模 0.1 张放入现有近似公式的代数结果。没有以 56.03 档重新交易，也没有任何新增净收益结果。

## 3. 下一步

1. 先保留 10ms 计量为推荐诊断口径；它降低了未匹配成交比例，同时完全保持原有下单/成交轨迹。
2. 重新验证强度模型的时间稳定性：同一训练/留出窗口总量高估约 29.5%，单纯缩短采样间隔未解决。优先跨日期复核时间段、模型结构和队列状态，不继续只靠更高频轮询减少几个未配对事件。
3. 只有在参数估计经多时段、队列假设、手续费/延迟稳健性检验后，才修正正式 G0 的 A/k 接口并重新做逐日净盈亏与成交后逆向选择，避免将本轮 56.03 档当成已验证最优价差。
