# Gate BTC 1.645σ：阶段④事前锁定的成交强度对照实验

制定时间：2026-11-16。必须先写明口径，再运行阶段④训练和评价。全部6—11月月首日已经被多轮研究使用，仍是探索性而非严格样本外。

## 目标与三组策略

正式比较原始GLFT（β=0）、已冻结Binance方向双边β1，以及两个新增**完全不利用Binance价格方向**的对照策略。对照模型都使用β=0、原始Gate GLFT每5s A/k与波动率参数估计、库存偏斜和库存上限、原始HBT 2.4.4撮合、Maker+0.02%实际收费、订单请求和回复各1ms、20ms同侧挂撤单间隔。

对照A（Static Widened GLFT）在原始GLFT双边报价外侧**各固定扩宽w个价格档**，不改变模型的仓位管理、时间驱动、成交模型。

对照B（Gate-only Local Volatility Pause）仅使用当前Gate历史600秒每100ms价格变化拟合的本地波动率sigma_G（单位tick/√s），超过冻结阈值时按原20ms限制取消在册可撤订单，并停止两侧新订单；恢复正常后继续原GLFT报价。没有Binance方向输入。

为了排除事件触发频率差异，A/B与原β0共享同一Binance到达的**事件时钟**，但两控制策略报价只使用Gate数据和本地库存，不使用Binance中间价、跨所残差和方向。

## 独立参数选择：2026-05-01

只使用**2026年5月1日**UTC 00:10–24:00（前10分钟预热，后名义1430分钟交易）作为独立参数选择日；6、7、8、9、10、11月的6个评价日期不得用于调参数。

- A：固定新增半价差 w∈{0.10,0.25,0.50,1.00}×H_May（单位tick，保留6位小数）。
- B：仅Gate波动暂停阈值为该日sigma_G经验{55%,70%,85%,95%}分位数（单位tick/√s，保留6位小数）。
- 各自分别运行4个完整May HBT，**只按实际成交笔数与同一May日正式β1成交笔数最接近**选参数，等差时选事先数组中顺序靠前的一项。May训练收益绝不进入参数选择。

## 正式评价：2026-06–11各月1日

每日期1430min，使用与已冻结原GLFT和双边β1**相同HBT撮合、数据、延迟、手续费、仓位限额和时间窗**。评价日只新跑A/B，不触碰官方原始GLFT和β1成交。核对Tardis四路输入的行数与首末本地采集时间与正式回测完全相同。

四个模型逐日记录实际成交笔数、名义成交额、平均绝对库存、库存均方根、每日最大库存、撤单请求和订单提交数，零手续费诊断权益与Maker+0.02%收费后净权益；基于官方成交本地回报起点和Tardis Gate原生quotes的100/500/1000ms有向Markout、P10和最差10%均值。两端中间价报价年龄≤500ms，UTC最后不足期限的样本排除。买卖侧分开记录，按日等权汇总。

**评价日若实际成交量/名义额未和β1接近，必须显示匹配偏差并明确判定为近似对照，不得再使用评价日调参。** 即使成交数接近，各模型的成交时刻、队列、库存和风险也不同；A/B仍只是较强的竞争基准，不是数学上的严格因果分解。

输出六日4模型统一表、逐日双控制相对于β1的费前/费后收益差、成交质量、库存分布、撤单成本和参数锁定记录。已探索六日不能表述为新样本外结果。资金费率、主动平仓费用与真实跨所时钟同步误差仍未建模。阶段⑤的单变量策略改进必须在观察该对照结果之后再决定。
