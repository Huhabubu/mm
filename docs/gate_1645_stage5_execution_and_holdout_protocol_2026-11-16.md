# 阶段⑤A—⑤C：执行和未探索历史日期预注册方案（2026-11-16）

## 5A 单侧机制消融

使用官方 hftbacktest 2.4.4、原同源 Gate 四流行情、Binance 额外可见延迟 2.5ms、订单提交与回报各1ms、同侧20ms操作限制、Maker正费用0.02%、GLFT 原始γ=50 USDT⁻¹（Gate代码0.0005）、滚动A/k/波动率、600s跨所基差、1σ锚和1.645σ门槛。六个2026-06至2026-11的月首日期，每日10min预热+1430min实际交易。禁止在这些研究过的六日选择新的β、γ、阈值或挂单距离。

比较四策略：冻结原GLFT β0、冻结双边 β1、冻结单侧外移 defensive_1p0、唯一新增的单侧暂停模型。当Binance正向有效信号发生，撤Gate卖侧并停止卖侧新挂单；当负向有效信号发生，撤Gate买侧并停止买侧新挂单；相反侧总用原GLFT报价；信号失效后正常报价。所有撤单均受20ms节流，交易所生效时序及队列继续交由HBT模拟。验收必须重放 defensive_1p0 与原冻结日账单（交易数、手续费、仓位、结算净权益）完全一致。三个既有模型原代码保持不变。

主指标为每独立UTC日实际扣Maker+0.02%的HBT净盯市权益，报告成交笔数/名义额、平均与均方根库存、峰值库存、实际撤单请求、提交订单、100/500/1000ms Markout及最差10%、报价有效率。六日均已探索，新的5A结果仍为探索性，不能声称未接触样本外。

## 5B 成交经济性

只读阶段②官方成交及原生quote、阶段③原GLFT信号分类和阶段④官方资金账簿。按同一笔原GLFT成交对齐价格，分组计算真实捕获价差、未来100/500/1000ms Markout及Maker实际费率后的短期中间价盯市诊断；另算冻结成交路径的盈亏平衡Maker手续费，区分成交额合并权重和独立日等权。严禁将短期诊断重复计入完整策略P&L。保持γ不变。
