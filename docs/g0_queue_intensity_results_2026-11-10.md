## 2. 泊松强度模型训练结果与留出验证

使用有实际有效挂单状态的曝光时间 E(d)（订单秒）及同距离真实模拟 maker 成交 N(d)（笔），估计 N(d) 的条件均值为 E(d)*A*exp(-k*d)。A 是每个有效 maker 订单每秒的理论成交强度，k 是每个实际价格档的距离衰减系数，d 是真实的价档距离。最大似然估计包含零成交但有曝光的价格档，并且从报价目标而非交易成交价推断实际距离。拟合范围 0.5–100 tick，86 个具有训练曝光的分组，其中最大实际有曝光拟合距离为 99.5 档。

| 项目 | 实测计算值 |
|---|---:|
| 训练估计 A（笔/有效订单秒） | 0.029325379 |
| 训练估计 k（每真实价档倒数） | 0.026254707 |
| 训练常数强度基准（笔/有效订单秒） | 0.019971354 |
| 留出期拟合范围内观察成交 | 156 笔 |
| 指数强度模型预测成交 | 204.852 笔 |
| 训练期常数强度基准预测成交 | 202.761 笔 |
| 留出期指数模型 Poisson deviance | 44.329（越小越好） |
| 留出期常数基准 Poisson deviance | 86.332 |

指数模型相对训练常数强度模型降低留出期泊松偏差，表明成交强度随真实报价距离的变化存在可利用的结构；但**总体成交数高估 48.852 笔，即相对观测的 31.3%**。九档都是同一段行情复用，模型不具跨交易日统计独立性；当前不能据此检验参数显著性。

若只把新估 A/k 和旧风险设定 gamma=0.05、订单数量 0.1 张、旧 sigma≈13.088815 tick/√秒代入 GLFT 报价公式，**半价差约 55.20 档（5.52 USDT/BTC）**。这只是数学诊断，**没有**以新参数重新交易回测。原 174.14 档存在训练距离半档单位错误，依然只保留为旧缺陷实现的对照。

## 3. 对模型可信度的判断

1. 队列一致成交：现在调用官方 hftbacktest 实际 maker 订单成交，不再把‘严格穿价’当成唯一的成交样本。先按 `NEW` 有效订单累计订单秒，区分 NONE 未接受、FILLED 已成交。
2. 回测核算：9 种距离×2 个时段的官方成交总数与成功追踪/未追踪之和逐项一致，头寸上界检验通过，数据转换与样本外运行完成。
3. 数值结果尚需改进：100ms 采样遗漏约 7.4% 训练成交和 10.3% 留出成交，且留出期总成交预测偏高约 31%。下一步建议细化曝光时间采样（例如 10ms，只修改计量频率，报价调整仍保持 100ms），并检验不同日期及队列模型，优先解决 unmatched 与过度预测。
4. 经济边界：maker 2bps 费用假设下 BTC 约 77,500 USDT/BTC 时单侧手续费约 15.5 USDT/BTC，远大于 55.2 档对应的 5.52 USDT/BTC；报价变窄与提高成交次数不能直接推出净盈利。

结论：**成交强度估计链路已成功切换为官方队列成交/有效存续时间，统计模型在留出期优于常数基准，但 100ms 曝光误差及总成交数高估使其仍属于诊断模型。正式 G0 暂不替换 A/k 参数。**
